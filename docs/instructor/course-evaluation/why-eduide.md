# Why EduIDE

## One consistent environment

Every student gets the same IDE with the same compiler, tools and settings.
The failure a student sees is the failure the grader sees.
"It works on my machine" stops being a category of support request.

## One click from Artemis

A student opens the exercise in Artemis and clicks **Open online IDE**.
The IDE starts with the repository already in place, and the Artemis view is ready for submitting.

## No installs

Students need a browser and a login.
There is no setup session in week one and no support for different operating systems.

## Capacity for labs and exams

The platform starts many sessions at once.
Warm pools keep idle sessions ready for a lab start, and operators can raise them for a fixed date.
Capacity is real but finite. Plan large starts with the platform team, see [Cohort Management](../course-operations/cohort-management.md).

## What it costs

You accept a managed environment, a network dependency and a platform team you rely on.
See [Limitations](../limitations/honest-limitations.md) and [Evaluating Course Fit](./course-fit.md).
