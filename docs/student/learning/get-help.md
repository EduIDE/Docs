# Get Help

Ask your tutor first when a problem is about your exercise or your course.
Use these channels when the problem is about EduIDE itself.

## Report a bug or request a feature

- On the launcher page, click **Report a bug** or **Request a feature** in the footer.
- In the IDE, open the **Help** menu and click **Report Issue**.

Both open the issue tracker on GitHub: `https://github.com/EduIDE/EduIDE/issues`.
You need a GitHub account.

:::warning Issues are public
Do not put personal data, Artemis links or exercise code into an issue.
Artemis links can contain access tokens.
:::

## Ask a question

Ask questions in the GitHub Discussions of the `EduIDE/EduIDE` repository.
