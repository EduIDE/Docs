# Get Help

Ask your tutor first when a problem is about your exercise or your course.
Use the channels below when the problem is about EduIDE itself.
Try [Troubleshooting](./troubleshooting.md) first.

## Who handles what

| Problem | Where to go |
|---|---|
| The start page, signing in, starting or stopping environments, saved workspaces, the status page | Issues of the platform: `https://github.com/EduIDE/EduIDE-control-plane/issues` |
| Inside the IDE: editor, terminal, languages, extensions, templates | Issues of the IDE: `https://github.com/EduIDE/EduIDE/issues` |
| Your exercise, grading, deadlines, access to your installation | The contact of your course |

In the IDE, **Help -> Report Issue** opens the IDE issue tracker.
The **Report a bug** link in the footer of the start page opens the tracker that your installation configures, by default the platform tracker above.
You need a GitHub account to open an issue.

:::warning Issues are public
Do not put personal data, Artemis links or exercise code into an issue.
Artemis links can contain access tokens.
:::

## Ask a question

Ask questions in the GitHub Discussions of the `EduIDE/EduIDE` repository, or ask your course contact.
